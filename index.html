RESEARCH NOTES

Metodologi & data

Transparansi sumber, asumsi, dan keterbatasan prototipe.

01

Data dan geografi

Peta dasar menggunakan OpenStreetMap melalui tile server publik. Titik contoh dibangkitkan secara sintetis di sekitar wilayah OKI. Batas area yang ditampilkan adalah cakupan kajian perkiraan, bukan batas administratif resmi.

02

Machine learning

Model JavaScript ringkas ditujukan untuk demonstrasi konsep. Random Forest dan boosting disederhanakan; SVM linear bukan kernel SVM. Metrik dihasilkan dari data sintetis.

03

Hotspot FIRMS

Jangan masukkan MAP_KEY ke file JavaScript publik. Untuk data aktual pada GitHub Pages, unduh CSV FIRMS secara terpisah dan unggah sebagai data publik setelah memeriksa lisensi serta metadata. Versi ini mendukung ekspor titik sintetis.

04

Model asap

Plume dibuat dengan adveksi dan difusi visual yang mengikuti arah angin pilihan. Belum mencakup topografi, tinggi injeksi, stabilitas atmosfer, deposisi, atau kimia aerosol.

Jalur pengembangan ilmiah

  1. Tentukan periode analisis dan unit prediksi per grid/per waktu.
  2. Integrasikan hotspot FIRMS/VIIRS dan area terbakar referensi.
  3. Selaraskan proyeksi, resolusi, dan waktu variabel lingkungan.
  4. Validasi spasial-temporal dan laporkan PR-AUC, ROC-AUC, F1, recall, kalibrasi serta ketidakpastian.
  5. Gunakan data meteorologi aktual dan model dispersi tervalidasi untuk analisis asap.
